## Cross-Expert Findings

### Common Workflows

| Pattern | Who uses it |
|---------|-------------|
| **0→80% AI draft + 20–30% human expert overlay** | Kevin Indig, Matt Diggity (70/30), Lily Ray (human story → AI format), Jonathan Boshoff |
| **Topic clustering before writing** | Matt Diggity, Aleyda Solís, Nathan Gotch, Kevin Indig |
| **SERP scrape → brief → draft → human review → publish** | Jonathan Boshoff, Daniel Agrici, Kevin Indig/AirOps, Matt Diggity |
| **Agent/automation pipeline (research → script → render → distribute)** | Julian Goldie, Gael Breton, Daniel Agrici |
| **Content refresh/decay monitoring loops** | Kevin Indig, Aleyda Solís |

### Common Tools

- **LLMs:** ChatGPT, Claude (Code), Gemini
- **Workflow automation:** n8n, Make/Zapier, AirOps
- **SEO data:** Semrush, Ahrefs MCP, DataForSEO, SISTRIX, AlsoAsked
- **Content optimization:** Surfer/SurferAI, Frase, Rankability Content Optimizer
- **Publishing:** WordPress/Webflow/Shopify APIs, Netlify
- **Video/voice:** HeyGen, ElevenLabs

### Common Production Systems

1. **Brief-first systems** — never raw-prompt to publish
2. **Human-in-the-loop checkpoints** at brief, draft, and pre-publish
3. **Brand memory layers** — CLAUDE.md, Obsidian vaults, fine-tuned personas
4. **Quality gates** — E-E-A-T checklists, helpful content guidelines, content validation skills
5. **Multi-surface distribution** — same core content → web + YouTube + LinkedIn

### Common Editorial Processes

- Expert/source material first; AI formats and scales
- Answer-first / chunk-level structuring for AI Overviews
- FAQ blocks, schema, standalone paragraphs
- Original data, case studies, first-hand experience as differentiators
- Read-aloud test for natural language (Matt Diggity)

### Common Quality Assurance Processes

- Google Quality Rater / Helpful Content guidelines checks (Boshoff)
- E-E-A-T comparison prompts (Boshoff, Diggity)
- Anti-"AI slop" humanization checks (Agrici claude-seo v2)
- Manual 5-minute review before auto-publish (Goldie)
- Query satisfaction / engagement metrics (Hellemans)

### Common Scaling Approaches

- Batch brief generation (30 drafts/quarter → editor polish)
- Programmatic enhancements at page level (Kevin Indig)
- Agent OS with Kanban task delegation (Goldie)
- Cloneable community workflows (Boshoff, Breton)
- Open-source Claude skills ecosystem (Agrici)

### Common AI Content Strategies

- **Topical authority > keyword chasing** (universal)
- **Non-commodity / do what AI can't** (Lily Ray, Nathan Gotch, Arnout Hellemans)
- **Structure for retrieval, not just ranking** (Aleyda, Matt Diggity, Nathan Gotch)
- **Search Everywhere Optimization** — web + YouTube + UGC as retrieval corpus (Gotch, Lily Ray)
